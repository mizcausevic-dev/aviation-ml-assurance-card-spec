# Why this draft exists

Aviation authorities are setting objectives for AI assurance while vendors and buyers still exchange much of the supporting posture in narrative documents. This draft tests whether a small, machine-readable disclosure can make intended use, ODD limits, dataset evidence, learning controls, and human responsibilities easier to inspect together.

It is deliberately narrower than a certification data package. The format records publisher statements and evidence references; it neither reproduces proprietary standards nor evaluates a real aircraft system. The accompanying dataset provenance tooling is a separate implementation and must be tested against its own inputs and outputs.

The Level 2B/3A override rule is a conservative Kinetic Gain disclosure choice. EASA material is cited with its actual proposal or concept-paper status in [SOURCES.md](SOURCES.md).
